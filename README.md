# Taraka Ram Donepudi - Portfolio

A responsive personal portfolio highlighting applied AI/ML, backend, streaming, and data analytics work.

## Run locally

Open `index.html` directly, or serve the folder with any static HTTP server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Stack

- Semantic HTML
- Modern CSS
- Vanilla JavaScript

The site is intentionally dependency-free and can be hosted with GitHub Pages.
